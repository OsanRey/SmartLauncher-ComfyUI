## Возможности

- **Установка ComfyUI:** мастер новой установки с выбором папки, Python, канала обновлений и профиля NVIDIA CUDA или CPU. Можно подключить уже установленный ComfyUI.
- **Запуск и остановка:** управление ComfyUI из главного окна. После запуска та же кнопка открывает интерфейс в браузере.
- **Обновления по вашему решению:** при открытии лаунчер проверяет обновления и показывает индикатор. Перед установкой можно посмотреть изменения и сравнить версии на GitHub.
- **Отдельная проверка окружения:** диагностика Python, зависимостей и PyTorch/CUDA из настроек. Обычное обновление ядра не пересоздаёт окружение и не обновляет PyTorch принудительно.
- **Загрузка моделей:** ссылки Civitai, Hugging Face и прямые ссылки на файлы; выбор файла, типа модели и папки назначения.
- **Очередь загрузки:** последовательное скачивание нескольких моделей, отмена текущей загрузки и очистка ожидающих. Закрытие окна загрузчика не прерывает очередь.
- **Custom Nodes:** установка по GitHub-ссылке, список установленных нод, проверка обновлений, обновление и удаление. Для нод из Registry используются возможности ComfyUI Manager.
- **Общие папки:** поддержка symlink/junction для каталогов `models` и `custom_nodes`, чтобы использовать одну коллекцию в нескольких установках.
- **Журналы и прогресс:** отдельные вкладки событий, консоли и предупреждений; прогресс запуска, генерации, скачивания и обслуживания.
- **Доступ по локальной сети:** включение LAN и копирование адреса ComfyUI прямо из главного окна.
- **Компоненты системы:** сведения об обязательных и дополнительных компонентах, их назначении и наличии.

## Установка

1. Скачайте **[SmartLauncher2.exe](https://github.com/OsanRey/SmartLauncher-ComfyUI/releases/latest/download/SmartLauncher2.exe)**.
2. Поместите файл в удобную папку и запустите.
3. Выберите **новую установку** или **подключение существующего ComfyUI**.
4. После настройки нажмите **Запустить ComfyUI**.

Для установки нужны **Git** и **64-битный Python 3.12–3.14 с Tkinter**. Для профиля NVIDIA нужен совместимый драйвер видеокарты. Сведения о компонентах доступны по кнопке **Система**.

Лаунчер управляет выбранной установкой ComfyUI. Модели и сторонние ноды добавляются отдельно.

## Как пользоваться

Нажмите **Запустить ComfyUI** и дождитесь готовности. Кнопка изменится на **Открыть в браузере**; автоматическое открытие можно включить в настройках. **Остановить** завершает работу ComfyUI.

Вкладка **События** показывает результаты операций. **Консоль** содержит полный вывод ComfyUI. **Предупреждения** собирают сообщения и рекомендации: текст можно выделять и копировать. Индикатор новых предупреждений сбрасывается при открытии вкладки, сами сообщения остаются.

История сохраняется при переключении вкладок и повторном запуске ComfyUI в том же сеансе лаунчера. Автопрокрутку можно отключить, чтобы спокойно прочитать нужный фрагмент.

## Основные настройки

| Настройка | Для чего |
| --- | --- |
| **Порт** | Адрес локального интерфейса; по умолчанию `8188`. |
| **Stable / Development** | Обновления по тегам версий или из ветки разработки ComfyUI. |
| **Доступ по LAN** | Открывает доступ к ComfyUI с других устройств локальной сети. Рядом с кнопкой браузера появляется копирование сетевого адреса. |
| **Manager** | Включает ComfyUI Manager при запуске. |
| **Открывать браузер** | Открывает страницу ComfyUI после готовности сервера. |
| **Дополнительные аргументы** | Параметры запуска ComfyUI, каждый аргумент на отдельной строке. |
| **Civitai / Hugging Face token** | Доступ к файлам, требующим авторизации. Токены сохраняются между сеансами. |
| **Проверить окружение** | Проверяет зависимости и профиль PyTorch/CUDA; при необходимости восстанавливает окружение. |
| **Компоненты** | Показывает требования и сведения о системных компонентах. |
| **Открыть папку журналов** | Открывает диагностические журналы для разбора ошибок. |

## Модели

Откройте **Модели**, вставьте ссылку и нажмите **Проверить**. Выберите файл, категорию и нажмите **Скачать**. Если загрузка уже идёт, кнопка добавит файл в очередь.

Доступны Checkpoint, Diffusion Model, LoRA, VAE, ControlNet, Text Encoder, CLIP Vision, Upscale Model, Embedding и произвольная папка. Категория определяет каталог назначения внутри `models`.

**Отменить текущую** отменяет только активный файл; остальные продолжают скачиваться по очереди. **Очистить ожидающие** убирает ещё не начатые загрузки. При временных сетевых ошибках лаунчер повторяет запрос и пытается продолжить скачивание, если сервер поддерживает докачку. Очередь и докачка не сохраняются после выхода из лаунчера.

Для закрытых файлов укажите токен соответствующего сервиса. Доступ зависит от прав аккаунта и условий самого источника.

## Custom Nodes

В окне **Модели** переключитесь на **Custom Nodes**. Вставьте GitHub-ссылку и нажмите **Установить или обновить**. Установка `requirements.txt` в окружение ComfyUI включается отдельной галочкой.

Ниже находится список установленных нод. **Обновить список** перечитывает папку, **Проверить обновления** запрашивает доступные версии. Для каждой поддерживаемой ноды доступны обновление и удаление. **Исправить зависимости** запускает восстановление зависимостей через ComfyUI Manager.

Перед изменением нод остановите ComfyUI. Локальные изменения в Git-ноде блокируют её обновление, чтобы не перезаписать ваши правки. Набор доступных действий зависит от способа установки ноды и её метаданных.

## Обновление ComfyUI

Проверка при открытии лаунчера ничего не устанавливает. Если обновление доступно, у кнопки **Обновить** появляется индикатор. Можно сразу запустить текущий ComfyUI или сначала открыть просмотр изменений и обновиться.

Если новой ревизии нет, обычное обновление завершается без установки пакетов. При изменении зависимостей синхронизируются необходимые корневые требования ComfyUI. Полное восстановление окружения запускается отдельно через настройки.

## Совместимость и данные

Лаунчер предназначен для **Windows x64**. Совместимость моделей и Custom Nodes зависит от выбранных версий ComfyUI, Python, PyTorch и самих расширений. Профиль CPU позволяет запускаться без NVIDIA, но скорость и поддержка отдельных моделей будут отличаться.

При включении LAN доступ может потребовать разрешения в брандмауэре. Эта настройка предназначена для доверенной локальной сети.

Настройки хранятся в `%LOCALAPPDATA%\SmartLauncherComfyUI2\profile.json`. Токены записываются в этот файл в открытом виде, а в диагностическом журнале скрываются. Не публикуйте файл профиля.

```powershell
.\.venv\Scripts\python.exe -m pip install "pyinstaller>=6,<7"
.\.venv\Scripts\python.exe build_exe.py
```

Результат сборки: `release_v2/SmartLauncher2.exe` в корне репозитория.
